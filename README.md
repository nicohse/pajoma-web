# pajoma® – Landing Page

Neue Startseite für pajoma® (Ingo Steyer GmbH & Co. KG, Hemmoor).
Händler gelangen über „Anmelden" in den bestehenden B2B-Shop: https://www.pajoma.de/html/de/login.html

## Aufbau

- `index.html` – die komplette Seite
- `assets/css/style.css` – Design
- `assets/js/main.js` – Menü, Animationen
- `assets/img/` – Bilder (Team, Marken)

Reines HTML/CSS/JS, kein Build-Schritt nötig.

## Testen mit GitHub Pages

Settings → Pages → *Deploy from a branch* → Branch `main`, Ordner `/ (root)` → Save.
Danach erreichbar unter `https://<github-name>.github.io/<repo-name>/`.
